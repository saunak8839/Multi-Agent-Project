# Account and technical help

## Trouble signing in

If a customer cannot sign in, first ask them to confirm that they are using the email address registered to the account and that there are no accidental spaces in the address. They can use the password reset option on the sign-in page. For security, support should never ask the customer to send their password or one-time verification code.

## Home router connection

For a home internet connection problem, ask whether other devices are affected and whether the router's internet indicator is on. The customer can power-cycle the router by unplugging it for 30 seconds, reconnecting it, and allowing several minutes for it to reconnect. If the connection remains unavailable, collect the router model, the approximate start time, and any displayed error so technical support can check service status and logs.

## Error messages

Ask the customer to share the exact error text or code and the time it occurred. Do not ask them to share passwords, payment card details, or authentication codes. Support should check current service status and relevant diagnostic logs before attributing the cause to the customer's device or account.
